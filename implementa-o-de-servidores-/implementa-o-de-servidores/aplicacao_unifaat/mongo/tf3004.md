# Modelagem e Consultas em MongoDB - Sistema de Entregas de Comida

Este documento contém a modelagem dos dados e as consultas necessárias para o sistema de entregas de comida, similar ao iFood ou Uber Eats. O sistema envolve quatro principais entidades: **Cliente**, **Entregador**, **Pedido** e **Produto**.

## 1. Modelagem dos Dados

### Entidades:
- **Cliente**
- **Entregador**
- **Pedido**
- **Produto**

### Decisão de Modelagem

#### Cliente
- **Referenciado**: O cliente é uma entidade que será acessada de forma independente (análise de pedidos, comportamento de compra), por isso é melhor armazená-lo separadamente e referenciá-lo nas coleções de pedidos.

#### Entregador
- **Referenciado**: Os entregadores são acessados de forma independente para análises de desempenho (quantidade de entregas, tempo médio de entrega, etc.), sendo mais eficiente referenciá-los nos pedidos.

#### Pedido
- **Embutido**: A estrutura do pedido contém dados específicos como lista de produtos, status e localização, e é conveniente embutir essa informação diretamente dentro do pedido para consultas rápidas.

#### Produto
- **Embutido ou Referenciado**: O nome e o preço do produto podem ser embutidos diretamente no pedido para facilitar consultas rápidas sobre os itens comprados. Caso precise de mais informações detalhadas sobre os produtos (ex.: categoria, estoque), pode-se referenciá-los em outra coleção.

### Estrutura Proposta:

```js
// Cliente
db.clientes.insertOne({
  _id: ObjectId("64b3f"),
  nome: "João Silva",
  email: "joao@email.com",
  telefone: "999999999"
});

// Entregador
db.entregadores.insertOne({
  _id: ObjectId("64b3e"),
  nome: "Carlos Mendes",
  email: "carlos@email.com",
  telefone: "988888888"
});

// Pedido
db.pedidos.insertOne({
  cliente_id: ObjectId("64b3f"),
  entregador_id: ObjectId("64b3e"),
  data: ISODate("2024-04-01T00:00:00Z"),
  status: "entregue",
  local: { type: "Point", coordinates: [-46.6333, -23.5505] },
  produtos: [
    { nome: "Pizza Calabresa", preco: 35 },
    { nome: "Coca-Cola 2L", preco: 10 }
  ]
});


2. Consultas

a) Retorne todos os pedidos entregues por "Carlos Mendes":

// Encontrar o entregador "Carlos Mendes"
const entregador = db.entregadores.findOne({ nome: "Carlos Mendes" });

// Buscar todos os pedidos entregues por ele
db.pedidos.find({ entregador_id: entregador._id, status: "entregue" });


b) Liste os nomes dos produtos e os totais de vendas (quantidade vendida) agrupados:

db.pedidos.aggregate([
  { $unwind: "$produtos" },  // Desestruturar a lista de produtos
  { $group: { 
      _id: "$produtos.nome",  // Agrupar por nome do produto
      total_vendas: { $sum: 1 }  // Contar a quantidade de vendas por produto
    }
  }
]);


c) Encontre pedidos entregues perto da coordenada [-46.634, -23.551] com raio de 1 km:

db.pedidos.createIndex({ local: "2dsphere" });  // Criar índice geoespacial (se ainda não existir)

db.pedidos.find({
  local: {
    $near: {
      $geometry: { type: "Point", coordinates: [-46.634, -23.551] },
      $maxDistance: 1000  // 1 km em metros
    }
  },
  status: "entregue"  // Considerando apenas os pedidos entregues
});


d) Retorne todos os pedidos que contenham o item "Pizza Calabresa":

db.pedidos.find({
  "produtos.nome": "Pizza Calabresa"
});

e) Projete apenas o nome do cliente e os nomes dos produtos do pedido:

db.pedidos.aggregate([
  { $lookup: {
      from: "clientes",
      localField: "cliente_id",
      foreignField: "_id",
      as: "cliente"
    }
  },
  { $unwind: "$cliente" },  // Desestruturar o cliente para acessar o nome
  { $project: {
      _id: 0,
      cliente_nome: "$cliente.nome",
      produtos: "$produtos.nome"
    }
  }
]);
